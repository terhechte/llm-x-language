# Scala Container

This container provides a Scala execution environment for the LLM benchmark framework.

## Structure

- `Dockerfile`: Defines the container image with Scala 3 and SBT
- `build.sbt`: SBT build configuration with dependencies
- `project/`: SBT project configuration
- `src/main/scala/Main.scala`: Main Scala source file (will be overwritten with generated code)

## Dependencies

- Scala 3.1.1
- SBT 1.6.2
- Circe (for JSON processing)
- STTP (for HTTP client)
- Akka HTTP (for HTTP server)
- Logback (for logging)

## Build Commands

```bash
# Build Docker image
docker build -t llm-benchmark/scala .

# Compile Scala code
sbt compile

# Run Scala application
sbt run

# Create fat JAR (optional)
sbt assembly
```

## Usage

The container is used by the framework to execute Scala code generated by LLMs. The generated code replaces `src/main/scala/Main.scala` and is compiled and executed within the container.

## Scala Features

- Functional and object-oriented programming
- Strong static typing with type inference
- Pattern matching
- Immutable data structures
- Actor model (via Akka)
- Future/Promise for async programming
