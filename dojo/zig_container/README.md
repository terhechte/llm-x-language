# Zig Container

This container provides a Zig execution environment for the LLM benchmark framework.

## Structure

- `Dockerfile`: Defines the container image with Zig compiler
- `build.zig`: Zig build configuration
- `src/main.zig`: Main Zig source file (will be overwritten with generated code)

## Dependencies

- Zig 0.11.0 compiler
- Standard library (included with Zig)

## Build Commands

```bash
# Build Docker image
docker build -t llm-benchmark/zig .

# Compile Zig code
zig build-exe src/main.zig

# Run Zig application
./main

# Or use build system
zig build
zig build run
```

## Usage

The container is used by the framework to execute Zig code generated by LLMs. The generated code replaces `src/main.zig` and is compiled and executed within the container.

## Zig Features

- Memory safe systems programming
- Compile-time code execution
- No hidden control flow
- No hidden memory allocations
- Cross-compilation support
