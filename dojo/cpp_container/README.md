# C++ Container

This container provides a C++ execution environment for the LLM benchmark framework.

## Structure

- `Dockerfile`: Defines the container image with GCC, CMake, and required libraries
- `CMakeLists.txt`: CMake build configuration
- `src/main.cpp`: Main C++ source file (will be overwritten with generated code)

## Dependencies

- GCC (latest)
- CMake
- libcurl (for HTTP requests)
- nlohmann/json (for JSON parsing)
- Boost (for additional utilities and HTTP server)

## Build Commands

```bash
# Build Docker image
docker build -t llm-benchmark/cpp .

# Compile C++ code
cmake .
make

# Run executable
./main
```

## Usage

The container is used by the framework to execute C++ code generated by LLMs. The generated code replaces `src/main.cpp` and is compiled and executed within the container.
