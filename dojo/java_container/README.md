# Java Container

This container provides a Java execution environment for the LLM benchmark framework.

## Structure

- `Dockerfile`: Defines the container image with OpenJDK 17 and Maven
- `pom.xml`: Maven project configuration with dependencies
- `src/main/java/Main.java`: Main Java source file (will be overwritten with generated code)

## Dependencies

- OpenJDK 17
- Maven
- Jackson (for JSON processing)
- OkHttp (for HTTP client)
- Spark Java (for HTTP server)
- SLF4J (for logging)

## Build Commands

```bash
# Build Docker image
docker build -t llm-benchmark/java .

# Compile Java code
mvn compile

# Run Java application
java -cp target/classes Main
```

## Usage

The container is used by the framework to execute Java code generated by LLMs. The generated code replaces `src/main/java/Main.java` and is compiled and executed within the container.
