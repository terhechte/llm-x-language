# Task: Type Check

Write C# code that compiles successfully and demonstrates proper type usage.

The code should:
- Use appropriate C# types and syntax
- Compile without errors
- Follow C# best practices

Example:
```csharp
public class Example
{
    public string Name { get; set; }
    public int Value { get; set; }
    
    public string GetDescription()
    {
        return $"{Name}: {Value}";
    }
}
```
