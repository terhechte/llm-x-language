# Lua Container

This container provides a Lua environment for executing LLM-generated Lua code.

## Dependencies

The following Lua libraries are available:
- dkjson: JSON encoding/decoding
- luasocket: Network support
- http: HTTP client functionality

## Setup

To install dependencies locally (if running outside of a containerized environment):

```bash
./setup.sh
```

This requires `luarocks` to be installed on your system.

## Usage

The main.lua file will be replaced with the actual code during benchmark execution.
